Acesso ao Copernicus

necessário para baixar as imagens do Sentinel-2

Credencial de cliente OAuth

Criada em dataspace.copernicus.eu → seu perfil → Sentinel Hub → User settings → OAuth clients → Create. É o caminho documentado para a Process API e não expira a cada sessão.

Fica guardado no armazenamento local deste navegador, nesta máquina — não é enviado para nenhum servidor nosso. Em computador compartilhado, use "Esquecer credencial" ao terminar.

Colar um token de acesso

Caminho direto quando o OAuth não passa (origem não autorizada no cliente costuma falhar como erro de CORS, sem mensagem). Gere o token e cole aqui — o app confere contra a API antes de aceitar e usa a validade que vem dentro dele.

como gerar o token

No terminal, com o seu client id e secret:

curl -X POST https://identity.dataspace.copernicus.eu/auth/realms/CDSE/protocol/openid-connect/token -d "grant_type=client_credentials" -d "client_id=SEU_ID" -d "client_secret=SEU_SEGREDO"

Copie o valor de access_token da resposta.

Ou entrar com a sua conta

Abre a página oficial do Copernicus; a senha é digitada lá, não aqui. A sessão expira e precisa ser refeita de tempos em tempos.

Metodologia do cálculo

Ei = A × B × C × EFi — o banco guarda só o A (área por classe). O resto é derivado daqui.

B = carga de combustível disponível, em toneladas de matéria seca por hectare. C = fração dessa carga que o fogo de fato consome (0 a 1). A biomassa consumida de cada mancha é área × B × C — por isso a coluna B×C, que é quantas toneladas saem de cada hectare queimado daquela classe.

Gramas de poluente por quilo de matéria seca queimada. Uma linha sem classe vale para todas as classes que não tiverem valor próprio. Poluentes de qualidade do ar (PM2.5, PM10, TPM, CO) e de efeito estufa (CO₂, CH₄, N₂O) convivem na mesma tabela.

Salvar não reprocessa nada: os valores passam a valer na próxima consolidação e no painel imediatamente.
