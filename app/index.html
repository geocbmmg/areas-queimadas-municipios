Credencial de cliente OAuth

Criada em dataspace.copernicus.eu → seu perfil → Sentinel Hub → User settings → OAuth clients → Create. É o caminho documentado para a Process API e não expira a cada sessão.

Fica guardado no armazenamento local deste navegador, nesta máquina — não é enviado para nenhum servidor nosso. Em computador compartilhado, use "Esquecer credencial" ao terminar.
